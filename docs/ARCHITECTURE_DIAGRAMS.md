信任边界与不变式：

- **唯一同步主链**：拼音转换引擎在按键线程同步完成；重排、整句、神经臂、云端、语音全部可失败/取消/未安装，纯 Rime 输入不受影响。
- **三条 IPC + 一条 HTTPS**：输入法↔本地推理、输入法↔云网关均为 owner-only 套接字（仅隔离其他系统用户，不防同 UID 恶意进程——显式不设防）；唯一网络出口在云网关，且只访问冻结白名单端点与模型。
- **云端最小授权**：请求不携带候选池；云端只做「生成/弃权」决策，不能指定上屏文本之外的内容；采纳必须用户显式确认。
- **Secure Input = 熔断**：阻断云请求、历史写入、在途采纳与反馈采集。
- **推理制品双轨**：开发环境浮点模型 + 神经臂；发布制品 INT8 量化（冻结集等价证明：top-1 一致率 99.38%）；发布打包尚未含神经臂依赖。

## 2. 一次击键的能力流：双延迟档与建议位仲裁

```mermaid
sequenceDiagram
    autonumber
    participant U as 用户/宿主应用
    participant UX as 输入体验（仲裁器+守卫）
    participant RIME as 拼音转换引擎（同步）
    participant LSY as 本地推理·同步路径
    participant LNE as 本地推理·神经臂
    participant GW as 云增强网关
    participant CM as 云端大模型

    U->>UX: 击键（拼音/标点/编辑）
    UX->>RIME: 同步转换（按键线程）
    RIME-->>UX: Rime 候选列表（数字位，始终可用）
    UX->>LSY: 增强请求（组合标识/修订号/会话/世代/截止时间）
    LSY-->>UX: 同步帧：重排序候选 + n-gram 整句建议
    Note over LSY: 语义排序 ⊕ 字符 n-gram ⊕ 用户语言模型<br/>整句仅产词典可证伪文本，置信门 0.60
    UX-->>U: 预编辑区（段焦点视图）+ 建议位初值
    LSY->>LNE: 异步整句解码（独立执行器，截止时间透传）
    LNE-->>UX: 神经整句迟到帧（100–300ms，按请求标识路由）
    alt 修订号匹配 ∧ 云未占槽 ∧ 非 Secure Input
        UX->>UX: 神经句接管同一建议位（最新请求获胜）
        Note over UX: 神经帧展示不设置信门槛（与云 0.60 门量纲不同，协议冻结）<br/>结构校验双侧把关（服务端 + 客户端字形/长度/可打印性）
    else 云已占槽 / 修订过期 / 会话失活
        UX->>UX: 静默丢弃（fail-closed）
    end
    Note over UX,LSY: 反向序兜底：神经帧已接管后，晚到的同步结果<br/>只消费在途额度、不改展示
    opt 云增强已开启（opt-in）
        UX->>GW: 决策请求（无候选池；五重绑定 + 截止时间）
        GW->>CM: 提示词（拼音 / 近期上下文 ≤600 字 / 分段结构）
        CM-->>GW: 决策
        GW-->>UX: 生成（整句 ≤128 字 或 续写联想）/ 弃权
        Note over UX: 客户端守卫链（顺序冻结）：<br/>安全输入 → 选择态 → 历史世代 → 截止时间 → 结果校验
    end
    opt 本地与云均无建议
        UX->>UX: 个性化短语填兜底建议位<br/>（精确 > 本域 > 个人学习 > 词库 > 频次）
    end
    U->>UX: Space / Tab / 数字 / 方向键
    Note over UX: Space=提交当前页第一候选（未翻页即 Rime 全局首选）<br/>Tab=接受 AI；跨段建议按段采纳、逐段复核后整句上屏<br/>末段部分选词不上屏、保留组合可回修<br/>任何失败/超时/失活 → 静默回退 Rime
```

能力流要点：

- **双延迟档**：同步档（重排 + n-gram 整句，随响应即达）先占建议位；神经档（小模型约束解码）迟到帧按最新请求获胜接管同一建议位；两档互不阻塞。
- **多段（跨标点）请求暂不走神经臂**，由同步整句 + 分段机制服务：焦点段定稿后自动向后重推后缀段，云端整句可按段采纳、用户逐段复核。
- **续写联想**是云端第二条决策路由：上屏后给出接续建议，Tab 接受、8s 自动隐藏、击键/切会话即撤销。
- **无空格中英混输**走本地保守分段：连续大写=强英文边界；全小写只认保守技术词/个人词，Tab 显式采用；Space 永远提交 Rime 首选。

冻结决策（D1–D7 摘要）：采集本地优先（默认零上传）；反馈最小单元=（输入，候选，采纳结果）三元组；训练数据可复现（内容指纹绑定）；云端只当教师出软标签、其生成文本不作金标；权重更新离线+显式+可灰度；**个性化优先落外挂层、不进权重**；一切产物可单独撤回并保留上一版。

任务链：**反馈采集（LM-003）→ 蒸馏数据管道（LM-004）→ 约束解码精调（LM-002）**——当前最高优先级；采集日志的进程归属（推理服务内置 vs 云网关旁挂）须实现前钉死。

演进主线一页读法：

1. **可靠性骨架先行**（08 月）：主链仲裁、置信度合同、语音与原生安全边界全部在增强功能之前定型。
