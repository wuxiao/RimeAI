# P0 放行证据

## 决定

状态：**PASS FOR INTERNAL P1 / BLOCKED FOR PUBLIC DISTRIBUTION**

P0 已证明在当前参考机上，本地专用排序与拼音约束长输入解码都能同时满足
质量和性能门。允许进入不公开分发的 P1 macOS 技术原型。

P2 公开预览仍被以下事项阻塞：

- 冻结数据和模型制品的 CC BY-SA/LGPL 分发方案尚未经法律审查。
- 当前 Homebrew librime bottle 不是受控最低部署目标构建。
- 已有 Apple Development 签名和可恢复 debug 安装/升级/卸载证据，但尚无
  Developer ID、公证、受信任输入源选择和真实应用支持矩阵证据。

## 被否决基线

### GTE multilingual reranker 306M

20 条真实追踪集上的最佳尝试仍把 conditional Top-1 降到 73.68%，P95
为 1.52s，冷启动约 24.55s。完整句配对更差。结论：检索相关性模型不适合
直接承担中文输入候选自然度排序。

### Qwen2.5-0.5B-Instruct

首批 5 条 Rime 未覆盖难例修复 0 条；热请求为秒级，且三种提示策略出现
候选锚定、过度生成或无关短输出。结论：当前通用 0.5B 指令模型既不满足
拼音正确性，也不满足 400ms 实时预算。

这两个模型保留版本锁和失败证据，但不进入 P1 运行时。
